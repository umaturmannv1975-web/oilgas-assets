Бизнес-процессы подхода

Какие бизнес-процессы нужны, чтобы матрица работала: от задачи этапа актива до решения на воротах, с ИИ-скиллами и ответственными людьми. Это проект процессной модели для обсуждения — названия ролей и регламентов уточняются при внедрении.

2. Основной процесс: от задачи этапа до решения на воротах

Вниз (сплошные стрелки) — декомпозиция задачи: этап актива → документы месторождения → документы объектов → расчёты. Вверх (пунктир) — сборка: расчёты → документ объекта → кросс-функциональный документ → решение ворот. На каждом переходе вверх — проверка человеком с ролью «отвечает»: ИИ готовит, человек подписывает.

3. Жизненный цикл скилла (расчёта)

Каждый из 77 расчётов проходит этот цикл один раз при создании и дальше живёт в каталоге скиллов с версиями. Владелец скилла — роль «О» из ролевой модели уровня 0.

4. Кто за что отвечает (RACI)

R — выполняет, A — утверждает и отвечает за результат, C — консультирует, I — информируется.
