Варианты оформления таблицы «4 колонки × 7 дизайнов»

Одни и те же данные в четырёх подачах. Нажмите на вариант, который ближе. Можно взять части из разных.

A

Компактная с раскрытием

Видны только названия дизайнов и число расчётов. Клик по дизайну раскрывает расчёты и софт. Чистый экран для первого показа, детали по требованию.

B

Таблица-матрица 7 × 4

Строки — номер дизайна 1–7, столбцы — направления. Всё выровнено по горизонтали, софт двумя плашками: 🌐 зарубежный / 🇷🇺 отечественный — сразу видно импортозамещение.

C

Адреса скиллов

Каждый расчёт получает адрес: G4.2, B1.3 … Это «прописка» скилла ИИ в матрице. Софт вынесен вниз колонки общим списком.

D

Презентационный слайд

Тёмный фон, крупные названия, полоска софта «зарубежный → отечественный» под каждым дизайном. Готов к экрану в переговорной.
