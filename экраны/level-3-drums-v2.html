Документы актива ↔ документы направлений

Сверху — кросс-функциональные документы жизненного цикла актива: российский документ и его мировой аналог. Пунктиром — мировые документы, у которых нет официального российского аналога. Выберите документ — барабаны направлений встанут на нужный функциональный документ. Привязки — черновик.

🇷🇺 российский документ + 🌐 мировой аналог 🌐 только мировой — российского аналога нет
