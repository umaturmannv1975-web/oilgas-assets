Уровень 0 · База данных

Как я вижу базу данных матрицы: каждый расчёт ИИ хранится с адресом (актив → месторождение → объект → этап → документ → дизайн → расчёт), с входными данными, версией результата, глубиной проработки, софтом и ответственной ролью. Тогда любой результат прослеживается до исходных данных и до документа, в который он вошёл. Это концепция для обсуждения.

Основа для данных недр — мировой открытый стандарт OSDU (Open Subsurface Data Universe) и модель PPDM; для российских компаний — корпоративные хранилища геолого-промысловых данных. Первый шаг — справочник адресов расчётов (77 кодов) и связь «расчёт ↔ документ ↔ этап»: она уже собрана в этой матрице и может стать первой таблицей базы. ⚠ — выбор платформы за ИТ-архитектурой компании.
