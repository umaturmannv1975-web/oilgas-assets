Уровень 0 · Расчёты в документах

Для каждого из 77 расчётов — в какие официальные документы он входит. Ф — функциональный документ: только своё направление (уровень 1, документы этапов объекта). КФ — кросс-функциональный: собирает расчёты нескольких направлений (уровень 2 — этапы месторождения, уровень 3 — этапы актива). Привязка расчётов к кросс-функциональным документам — черновик, ⚠ сверить.
